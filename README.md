# sql-datawarehouse-project
Contrucción  de DWH,  con SQL Server, inclyendo procesos ETL, modelado de datos y análitica.
## 📝 Introducción

Este proyecto presenta el **diseño e implementación de un Data Warehouse (DWH)** orientado al **análisis de información empresarial**.

La solución parte de datos provenientes de sistemas operacionales, los cuales son sometidos a procesos de **extracción, transformación y carga (ETL)** para posteriormente ser integrados en un repositorio diseñado para **consultas analíticas y generación de indicadores**.

El proyecto implementa un **modelo dimensional**, compuesto por **tablas de hechos y dimensiones**, permitiendo analizar las operaciones desde diferentes perspectivas, como **tiempo, clientes, productos y transacciones**.

El objetivo es construir una solución cercana a un escenario empresarial, aplicando buenas prácticas de:

- **Modelado dimensional**
- **Integración y transformación de datos**
- **SQL**
- **Procesos ETL**
- **Calidad y consistencia de datos**
- **Análisis de información**
- **Business Intelligence (BI)**

Finalmente, el Data Warehouse proporciona una base estructurada para el consumo de información mediante herramientas de **visualización y análisis**, facilitando la construcción de **KPIs, reportes y dashboards orientados a la toma de decisiones**.

## 🎯 Objetivo

Diseñar e implementar un **Data Warehouse funcional** que permita transformar datos operacionales en información estructurada, confiable y preparada para el **análisis empresarial y la generación de indicadores**.

## 🏗️ Arquitectura

> **Fuentes de datos → ETL → Data Warehouse → Modelo dimensional → BI / Dashboards**
